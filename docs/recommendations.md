# Рекомендации: как считаются очки

Всё считается на сервере (`Server/server.py`, раздел «вкус»). По каждой **теме** (из текста поста) и каждому **автору**
копится оценка. Плюс поднимает похожее в «Для вас» и шортсах, минус опускает. Оценки со временем затухают: «сейчас» — за 3 дня,
«раньше» — за 30 дней. Свои посты на вкус не влияют.

**«Учитывать мои действия»** (Профиль → Конфиденциальность, по умолчанию включено). Выключено — очки не копятся и не
используются, лайки тоже не учитываются: лента строится только по интересам, выбранным при регистрации, свежести и популярности.
Интересы выбираются один раз при регистрации — менять их в приложении негде.

## Очки за действия (`TASTE_W`)

| Действие | Очки |
|---|---|
| Комментарий | +4 |
| Лайк / снял лайк | +3 / −3 |
| Сохранил / убрал из сохранённых | +3 / −1.5 |
| Репост к себе | +5 |
| Поделился (переслал в чат, скопировал ссылку) | +5 |
| Поиск (темы из запроса в поиске шортсов) | +2 |
| Вернулся и посмотрел ещё раз (через 10+ минут) | +2 сверху к очкам за просмотр |
| «Не интересует» / жалоба | −8, и пост скрывается навсегда |

## Сколько смотрел

Посты в ленте (`dwell_weight`, по времени на экране):

| Время | Очки |
|---|---|
| меньше 1 с — сразу пролистнул | −0.6 |
| 1–3 с | +0.1 |
| 3–8 с | +0.6 |
| 8–20 с | +1.0 |
| больше 20 с | +1.4 |

Шортсы (`reel_weight`, по доле ролика; больше 1 — пересматривал в том же заходе):

| Доля | Очки |
|---|---|
| меньше 12 % — сразу пролистнул | −1.2 |
| 12–30 % | −0.2 |
| 30–60 % | +0.6 |
| 60–90 % | +1.2 |
| досмотрел (до 1.5) | +2.0 |
| пересмотрел (до 2.5) | +2.6 |
| крутил несколько раз | +3.2 |

## «Не интересует»

Пост записывается в `hidden_posts` и больше никогда не попадает в ленту (`/v1/posts`, в том числе «Для вас») и шортсы
(`/v1/reels`); репосты этого поста — тоже. Открыть его можно, только если его пришлют (прямая ссылка `/v1/posts/<id>`)
или человек найдёт его сам (поиск, профиль автора). Скрытие работает, даже если рекомендации выключены.
