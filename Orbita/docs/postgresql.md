# База данных: SQLite и PostgreSQL

Сервер Orbita умеет работать с двумя базами, код запросов один и тот же:

- **SQLite** — по умолчанию. Ничего настраивать не надо, файл `~/.orbita/data/orbita-v2.db`.
  Отлично подходит для локального запуска, разработки и небольшой нагрузки.
- **PostgreSQL** — для продакшена. Выдерживает большие объёмы данных, нормальные бэкапы,
  репликацию и доступ по сети. Включается одной переменной окружения.

Переключение — только через `DATABASE_URL`. Код сервера переписывать не нужно: адаптер
(`Server/dbadapter.py`) на лету переводит SQLite-запросы в диалект Postgres (плейсхолдеры,
`INSERT OR IGNORE/REPLACE`, типы `BLOB`/`REAL` и т. п.).

## Что хранится и как с шифрованием

Шифрование полей (имена, тексты сообщений, телефоны — AES-256-GCM) работает одинаково в обеих
базах: в Postgres зашифрованные поля лежат в колонках типа `BYTEA`. Мастер-ключ по-прежнему живёт
в файле `~/.orbita/keys/master.key` **вне базы** — его, как и раньше, надо хранить отдельно и в
безопасности. Без него данные не расшифровать, в какой бы базе они ни лежали.

Медиафайлы (фото, видео, голосовые) лежат в папке `~/.orbita/data/media-v2`, а не в базе — это не
меняется.

## Включить PostgreSQL

1. Поставить и запустить PostgreSQL 14+ (на отдельной машине или рядом с сервером):

   ```bash
   sudo apt install postgresql
   ```

2. Создать базу и пользователя (кодировка обязательно UTF-8):

   ```bash
   sudo -u postgres psql <<'SQL'
   CREATE USER orbita WITH PASSWORD 'ПРИДУМАЙ_ПАРОЛЬ';
   CREATE DATABASE orbita OWNER orbita ENCODING 'UTF8';
   SQL
   ```

3. Поставить драйвер Python:

   ```bash
   pip install psycopg2-binary
   ```

4. Передать серверу адрес базы и запустить:

   ```bash
   export DATABASE_URL="postgres://orbita:ПРИДУМАЙ_ПАРОЛЬ@127.0.0.1:5432/orbita"
   python3 Server/server.py
   ```

Таблицы и индексы сервер создаёт сам при первом запуске (как и на SQLite). В логе при старте
по-прежнему видно папку данных и отпечаток мастер-ключа.

## Перенос данных со SQLite на PostgreSQL

Таблицы с обеих сторон совпадают по именам и колонкам. Самый простой путь — `pgloader`:

```bash
sudo apt install pgloader
pgloader ~/.orbita/data/orbita-v2.db \
  "postgres://orbita:ПАРОЛЬ@127.0.0.1:5432/orbita"
```

Зашифрованные поля переносятся как есть (байты), расшифровка идёт тем же мастер-ключом — поэтому
ключ `master.key` переносить вместе с данными обязательно.

После переноса запускай сервер с `DATABASE_URL`, указывающим на Postgres, а SQLite-файл можно
убрать в архив.

## Заметки о работе

- Соединение с Postgres одно, общее, в режиме autocommit — весь доступ к базе сервер и так
  сериализует общим замком (как было с единственным писателем SQLite), поэтому поведение
  запросов полностью совпадает. При обрыве соединения адаптер переподключается сам.
- Клиентская кодировка форсируется в UTF-8, так что эмодзи и кириллица хранятся корректно даже
  если кластер создан в непривычной локали.
- Вернуться на SQLite можно в любой момент — просто убери `DATABASE_URL` и перезапусти сервер.
