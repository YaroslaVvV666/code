## Запуск сервера

```
cd Server
python3 server.py            # http://0.0.0.0:8080, данные в Server/data
```

* Симулятор: адрес `http://localhost:8080` (стоит по умолчанию).
* Реальный iPhone: Профиль → Сервер → `http://<IP вашего Mac в Wi-Fi>:8080`.
* Посты, фото, видео, профили и комментарии хранятся на сервере и видны всем, кто к нему подключён.

## Настройки проекта Xcode (один раз)

Target → Info → добавить:

| Ключ | Значение |
|---|---|
| App Transport Security Settings → Allow Local Networking | YES |
| Privacy - Local Network Usage Description | Orbita подключается к вашему серверу в локальной сети |
| Privacy - Camera Usage Description | Камера нужна, чтобы сканировать QR-коды Orbita |
| URL Types → URL Schemes | `orbita` (identifier: com.orbita.link, role: Viewer) |

Схема `orbita://` нужна, чтобы QR-код профиля, отсканированный обычной «Камерой», открывал Orbita.

Выбор фото и видео (PhotosPicker) и файлов музыки (fileImporter) отдельного разрешения не требует.
Чтобы музыка продолжала играть при заблокированном экране: Signing & Capabilities → Background Modes → Audio.

## Что где хранится

| Данные | Место |
|---|---|
| Номер, почта, имя, пароль (хэш), настройки, сессия | iPhone: зашифрованная SQLite (AES-256-GCM), ключи в Keychain |
| Профиль (@username, о себе, аватар), посты, медиа, лайки, комментарии | Сервер: `Server/data` |

## Профиль

* **Изм.** (слева сверху) — «Изменить профиль»: фотографии (добавить, удалить, перетащить для смены порядка, «Сделать основным»),
  имя, фамилия, о себе, день рождения (можно без года), номер телефона (с подтверждением кодом), имя пользователя.
* Фотографий может быть до 50. Под каждой — дата добавления; в профиле они листаются по кругу аватарки, по тапу открываются на весь экран.
* Кнопка QR (справа сверху) показывает только QR-код профиля: `orbita://u/<username>` (или `orbita://id/<id>`, если имени пользователя нет).
  Его открывает «Камера» iPhone и перебрасывает в Orbita. Для ссылок вида https:// нужен свой домен и Universal Links.
* Профиль → Устройства: список сеансов (устройство, версия, IP, последняя активность), завершение сеанса, «Подключить устройство».

## Вход по QR-коду

1. На новом устройстве: экран входа → «Зарегистрироваться по QR-коду» — показывается QR (код живёт 2 минуты и обновляется).
2. На уже вошедшем: Профиль → Устройства → «Подключить устройство», навести камеру на код.
3. Появится запрос с названием и IP нового устройства; после «Подтвердить вход» новое устройство входит в тот же аккаунт.

4. Если в аккаунте включён облачный пароль (2FA), новое устройство после подтверждения попросит пароль. Сеанс сервер выдаёт только после верного пароля;
   после 5 ошибок вход блокируется на 5 минут.

Токен выдаётся один раз тому, кто создал QR (по секрету, который не попадает в код). Подтверждайте только коды со своих устройств.

### Данные аккаунта на сервере

Имя, интересы, облачный пароль (хранится как scrypt-хэш), почта и настройки (язык, тема, акцент) лежат на сервере в зашифрованном виде.
Выход из аккаунта ничего не стирает: при следующем входе (по номеру или по QR) имя и интересы не спрашиваются, а пароль, почта и настройки возвращаются.
Вход по номеру с 2FA: код из SMS, затем пароль. Старые аккаунты, где пароль был только на телефоне, переносят его на сервер при первом верном вводе.

## Комментарии

Лайк (иконка + число, как в TikTok), ответы (ветки под корневым комментарием), закрепление (только автор поста).
Если комментарий лайкнул автор поста, в его углу появляется маленькая аватарка автора.

Настройка провайдеров — в `Server/README.md` («Настоящие SMS и письма с кодом»). Без неё приложение показывает код баннером (учебный режим).

## Профиль

Как в Telegram: по центру круглая аватарка, имя, «в сети», бегущая строка с музыкой, карточка с данными
(значение цветом, подпись мелко снизу) и вкладки «Публикации / Фото». **Потяните страницу вниз** — фото
раскроется на всю ширину (полоски сверху, тап слева/справа листает, по центру — открыть). Просмотр аватарок:
сверху «назад | имя и дата | Изм.», счётчик «N из M», лента миниатюр, внизу «поделиться» и корзина;
«Изм.» → «Сделать основным» / «Изменить порядок» / «Удалить».

## Страница, стена, приватность, музыка

- **Страница** (Профиль → «Моя страница», тап по аватару автора в ленте или QR-код): обложка, аватар, статус, бегущая строка
  с первым треком, информация, счётчики, стена карточками как во ВКонтакте / Facebook. На своей странице — «Что у вас нового?».
- **Публикации**: меню «⋯» → «Редактировать» / «Удалить» (с подтверждением). У изменённых — пометка «изм.».
- **Конфиденциальность** (как в Telegram): Чёрный список, Двухфакторная аутентификация, Почта для входа, переключатель «Закрытая стена»
  (прячет только стену), «Кто видит»: номер, время захода, фотографии, «О себе», день рождения, музыка, комментарии;
  звонки, пересылка и приглашения пока только сохраняются.
- **Плейлист**: «Моя страница» → «Плейлист» → «+» (любой mp3 / m4a). Порядок меняется кнопкой «Изм.», удаление — свайпом.
  Название и исполнитель берутся из тегов файла. Трек №1 бегущей строкой под ником; «Добавить музыку» видит только владелец.

## Быстрый запуск (одна команда)

```bash
bash start.sh
```

Скрипт сам создаёт venv, ставит зависимости, определяет IP Мака, запускает сервер и печатает адрес
и QR-код `orbita://server?url=http://IP:8080`. Наведите камеру iPhone на QR — приложение подставит
адрес сервера. Либо введите адрес вручную: Профиль → Сервер. Телефон и Мак должны быть в одной Wi-Fi сети.
Без настроенных SMS/почты включается dev-режим: коды показываются в консоли сервера.

Одноразовые настройки в Xcode (Info): App Transport Security → Allow Local Networking = YES;
`NSLocalNetworkUsageDescription`, `NSCameraUsageDescription`, `NSMicrophoneUsageDescription` (голосовые и «кружки»), `NSSpeechRecognitionUsageDescription` (расшифровка голосовых), `NSContactsUsageDescription` (поиск друзей в записной книге);
URL Types → схема `orbita`;
Background Modes → Audio.

## Комментарии

Комментарии — дерево: ответ привязан к конкретному комментарию, ветки свёрнуты и раскрываются
по «Показать ответы (N)», внутри можно отвечать дальше на любую глубину.
Имя профиля может содержать любые символы (кастомный ник).

## Форматирование текста

В редакторе поста выделите текст — в меню появится пункт «Формат» (как в Telegram): жирный, курсив,
подчёркнутый, зачёркнутый, маркер, цитата, моноширинный, ссылка, «Обычный» (сброс). Те же стили есть
на панели над клавиатурой. Ссылки в тексте открываются по нажатию.

## Мессенджер

Вкладка «Чаты» устроена как в Telegram:

- **Список**: непрочитанные, «печатает… / записывает голосовое…», галочки доставки и прочтения, новый чат по @нику (карандаш).
- **Переписка**: пузыри со сгруппированными углами, дни-разделители, свайп влево — ответить, долгое нажатие — меню
  (ответить, копировать, изменить, удалить «у меня» / «у всех»), кнопка «вниз», нижняя панель вкладок прячется, свайп от края — назад.
- **Ввод**: слева скрепка (фото/видео/файл — можно отправлять без подписи), в поле работает форматирование
  (выделил → «Формат»), справа в поле смайл: панель эмодзи и стикеров вместо клавиатуры. Справа от поля:
  стрелка отправки, а если поле пустое — микрофон. **Нажатие** на микрофон превращает его в камеру (и обратно);
  **удержание** — запись голосового (микрофон) или видео-«кружка» (камера); влево — отмена.
- **Голосовые** с волной и скоростью 1×/1.5×/2×, **«кружки»** (до 60 с), **файлы** (до 80 МБ, открываются через просмотр iOS),
  **фото и видео** (по нажатию — на весь экран).
- **Стикеры**: два набора («Космос», «Эмоции») лежат в `Server/stickers/`, генерируются `python3 Server/make_stickers.py`;
  свои — положите PNG в папку набора и добавьте в `packs.json`. Стикеры можно прикреплять и к публикациям (кнопка «Стикеры» в редакторе поста).
- Всё шифруется на сервере (AES-256-GCM), в том числе вложения; обновление — опросом раз в 2 с, плюс push.

### Музыка в переписке

Пришёл mp3 / m4a — в пузыре обложка (из тегов), название и исполнитель. Нажали — играет, а под шапкой чата
появляется полоска «играет»: название, сколько прослушано, пауза и закрыть. Нажали на полоску — большой плеер
как в Spotify: обложка, перемотка, большие «назад / пауза / вперёд», повтор. Снизу «Следующая песня» —
раскрывается в список всей музыки из этой переписки. Кнопка **«Добавить в профиль»** копирует трек в ваш плейлист
(файл перешифровывается под вас; удаление оригинала у собеседника вашу копию не трогает). Свои mp3 отправляются
через скрепку → «Файл»: теги и обложка читаются автоматически.

### Профиль переписки

Нажмите на имя вверху чата — откроется профиль, как в Telegram: аватар, статус, данные (телефон, @ник, о себе),
кнопки «Профиль / В контакты / Заблокировать» и вкладки **Медиа, Файлы, Музыка, Голосовые** (появляются только если
такое было в переписке). «В контакты» позволяет дать человеку своё имя — оно видно только вам, во всех чатах и списках.

### Группы, каналы и «Сообщества»

Создать: вкладка «Чаты» → карандаш → **Новая группа / Новый канал**, либо «+» на вкладке **Сообщества**.
- **Тип**: закрытый (по приглашению или ссылке) или публичный (виден в каталоге и поиске, можно задать короткую ссылку
  `http://сервер/g/имя`). Ссылка открывает страницу с кнопкой «Открыть в Orbita».
- **Заявки на вступление**: админы подтверждают или отклоняют каждого (в профиле чата и в «Изменить»).
- **Роли**: владелец, админы (долгое нажатие на участнике → «Сделать админом»), участники. Удалённый админом участник
  попадает в список «Удалённые» и не может вернуться по ссылке, пока его не разрешат.
- **Параметры группы**: кто может писать (все / только админы), медленный режим (10 с … 1 ч), история для новых участников,
  запрет копирования, без звука для себя.
- **Канал**: писать могут только админы; подписчиков видят только админы (остальным показывается число); у постов
  счётчик просмотров; подписаться, отписаться, выключить звук.
- **Сообщества**: каталог публичных каналов и групп с поиском и фильтром «Все / Каналы / Группы», сверху — ваши.
- Владелец может удалить группу или канал для всех.
- Приглашение: из контактов, по @нику или ссылкой через системное «Поделиться».
- Запрет копирования скрывает «Копировать» в приложении; скриншоты и пересылку вручную он не блокирует.
- Известные ограничения: у админов нет отдельных прав (все админы равны), у каналов нет комментариев и подписи автора.

### Друзья из контактов и уведомления «теперь в Orbita»

- Профиль → «Найти друзей из контактов» (также в «Новом чате» и карточкой в начале списка чатов): приложение читает номера
  из записной книги и отправляет их на сервер, сервер сравнивает их с номерами пользователей и возвращает совпадения.
  Найденных можно добавить в контакты под именем из записной книги одним нажатием.
- Номера сравниваются по защищённому индексу (HMAC с ключом сервера); сервер хранит загруженный список (имя шифруется),
  чтобы потом сообщить, что знакомый зарегистрировался. «Удалить загруженные контакты» стирает список.
- Когда человек из вашей записной книги заходит в Orbita, вам приходит push «Имя теперь в Orbita» (если настроен APNs),
  а в списке чатов появляется карточка с кнопкой «Написать».
- Конфиденциальность → «Найти меня по номеру» (все / никто). При «никто» вас не найдут и никого не уведомят.
- Номер телефона сервер получает от приложения при каждом запуске; он **не подтверждается кодом на сервере**, поэтому
  в продакшене подтверждение номера (SMS/звонок) лучше добавить.

### Вибрации и баннеры

- Один выключатель: Профиль → «Вибрация». Вибрация — при новом входящем сообщении в открытом чате, при баннере
  о сообщении в другом чате, при новом «знакомом в Orbita», отправке, записи и прочих действиях.
- Если вы в другой вкладке или в другом чате, сверху появляется баннер нового сообщения (нажатие открывает чат).
- Уведомления на заблокированном экране — это только APNs (см. ниже). Без платного аккаунта разработчика и настроенного
  `push.py` работают лишь баннеры и вибрации внутри открытого приложения.

## Push-уведомления (APNs)

Сообщения приходят на экран блокировки, даже если Orbita закрыта. Требуется **платный Apple Developer Program**
(на бесплатном Personal Team push недоступен) и **реальный iPhone** (в симуляторе push нет).

1. developer.apple.com → Certificates, Identifiers & Profiles → Keys → «+» → включить *Apple Push Notifications service (APNs)* →
   скачать `AuthKey_XXXXXXXXXX.p8` (скачивается один раз). Запомните Key ID и Team ID (Membership).
2. Xcode → Target → Signing & Capabilities → «+ Capability» → **Push Notifications**.
3. Запуск сервера с ключом:
```bash
ORBITA_APNS_KEY_FILE=~/AuthKey_XXXXXXXXXX.p8 ORBITA_APNS_KEY_ID=XXXXXXXXXX \
ORBITA_APNS_TEAM_ID=YYYYYYYYYY ORBITA_APNS_TOPIC=com.ваш.bundleid bash start.sh
```
   В консоли должно появиться «Push (APNs): включены».
4. Запустите приложение на iPhone, разрешите уведомления, войдите. Сборка из Xcode использует sandbox-APNs,
   TestFlight/App Store — production (выбирается автоматически).

Текст сообщения в уведомлении можно скрыть: `ORBITA_PUSH_PREVIEW=0`. Сервер должен иметь выход в интернет к `api.push.apple.com:443`.
Токены устройств хранятся на сервере в зашифрованном виде и удаляются при выходе из аккаунта и завершении сеанса.

## Фотографии профиля (как в Telegram)

В шапке — текущая (главная) аватарка со счётчиком фото. Нажатие открывает просмотр на весь экран: полоски сверху,
«N из M», свайп по фото и лента миниатюр внизу (удобно, когда фото много). В своём профиле в меню «…» — «Сделать основным»
и «Удалить фото». Лимит — 50 фото на аккаунт (проверяет сервер).

## Ссылки на посты

«Поделиться» у поста даёт обычную ссылку `http://адрес-сервера/p/<id>`: она кликабельна в любом мессенджере,
открывает страницу-переходник и перекидывает в Orbita (`orbita://post/<id>`). Внутри приложения такие ссылки
(в чатах, постах) открываются сразу, без браузера. Ещё есть «Скопировать ссылку» и «Отправить в чат» (выбор собеседника).
Ссылка работает у тех, кто подключён к тому же серверу. Пост заблокированного автора по ссылке не открывается.

## Звонки (WebRTC)

Голос и видео идут напрямую между телефонами, сервер Orbita передаёт только сигналы (в памяти, на диск не пишутся).

1. Xcode ▸ File ▸ Add Package Dependencies ▸ `https://github.com/stasel/WebRTC` ▸ продукт **WebRTC** в цель приложения
   (если собираете через `xcodegen`, пакет уже прописан в `project.yml`). Без пакета приложение собирается, а звонок сообщает, что WebRTC не подключён.
2. Для связи через мобильный интернет и разные сети нужен TURN-сервер (иначе работает только там, где прямое соединение возможно):
   `apt install coturn`, затем в окружении сервера Orbita:
   `ORBITA_TURN_URL=turn:ВАШ_IP:3478,turn:ВАШ_IP:3478?transport=tcp ORBITA_TURN_USER=orbita ORBITA_TURN_PASS=пароль`
   (в `/etc/turnserver.conf`: `lt-cred-mech`, `user=orbita:пароль`, `realm=orbita`, `fingerprint`; открыть порты 3478 и 49152–65535/udp).
3. Входящий звонок виден, пока приложение открыто (опрос раз в ~2 секунды). Когда приложение закрыто, приходит обычный push «Входящий звонок».
   Полноценный звонок на заблокированном экране (CallKit + VoIP push) требует платного аккаунта Apple Developer.


## Запись голосовых и кружков
Зажмите микрофон/камеру и потяните вверх к замку — запись закрепится, палец можно убрать. Внизу появятся «Отмена» и кнопка отправки.
Влево — отмена. На экране видеозвонка внизу мелким шрифтом показано состояние (камера / связь / видео собеседника) — по нему видно, где обрыв.

## Демонстрация экрана и просмотр медиа
В видеозвонке кнопка «Экран» показывает собеседнику экран. Без расширения — только экран самого приложения (ReplayKit). С расширением `Extension/Broadcast` — весь экран телефона, в том числе когда приложение свёрнуто: нажали «Экран» → системное окно «Начать вещание» → можно выходить из Orbita.
Как подключить расширение вручную в Xcode: File ▸ New ▸ Target ▸ Broadcast Upload Extension (без UI), Product Name `OrbitaBroadcast`; замените созданный SampleHandler.swift файлом `Extension/Broadcast/SampleHandler.swift`; Bundle ID расширения = ID приложения + `.broadcast`; у обоих таргетов (приложение и расширение) Signing & Capabilities ▸ + Capability ▸ App Groups с одной группой `group.<ID приложения>`. Через xcodegen (`setup_xcode.sh`) всё это уже прописано в project.yml, нужно только заменить `com.example` на свой префикс в project.yml и в обоих .entitlements.
Кадры идут из расширения в приложение по сокету в папке App Group; приложение остаётся живым в фоне, пока идёт звонок.
Фото и видео из чата открываются общей галереей («3 из 12»), кнопка сохранения кладёт файл в «Фото» (ключ `NSPhotoLibraryAddUsageDescription`).

Автовоспроизведение: настройка «Автовоспроизведение видео» (Профиль ▸ Настройки) теперь действует и в чатах — видео до 40 МБ играет без звука прямо в переписке.

## Интересы и рекомендации
При регистрации предлагается выбрать до 10 интересов (можно один или пропустить), потом их можно поменять в Профиль ▸ Интересы. Лента имеет режимы «Для вас» (темы постов, лайки, свежесть, популярность) и «Свежее». Сервер: `GET/PUT /v1/me/interests`, `GET /v1/posts?sort=for_you`.
Почта и двухфакторная защита больше не входят в регистрацию — добавляются в настройках. У пароля есть подсказка; для смены пароля нужен прежний. Номер меняется по коду из SMS на новый номер, письму на привязанную почту и паролю 2FA (если они включены).

## Редактор шортсов
Features/Reels: ReelEditor (UI), ReelEditModel (состояние/плеер), ReelRender (CoreImage-композиция, слайд-шоу, сборка с музыкой). Монтаж выполняется на устройстве, сервер получает готовый mp4.

## Анимированные эмодзи (Lottie)

Реакции в чате анимированы: огонь горит, палец показывается, сердце бьётся, а при выборе реакции над сообщением играет крупная анимация.

1. Xcode → File → Add Package Dependencies → `https://github.com/airbnb/lottie-ios` (от 4.5.0), добавьте библиотеку Lottie в приложение. С xcodegen пакет уже прописан в `project.yml`.
2. Сами анимации не лежат в проекте: приложение загружает их из набора Noto Animated Emoji (Google, лицензия CC BY 4.0, нужно указать авторство) при первом показе и сохраняет в кеш телефона.
3. Без пакета Lottie или без сети показываются обычные эмодзи, всё остальное работает.
